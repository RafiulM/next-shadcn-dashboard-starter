## 🚀 Getting Started

### Prerequisites

Before you begin, ensure you have the following installed on your system:
- **Node.js** 18.17 or later
- **npm** or **yarn** or **pnpm** package manager
- **Git** for version control
- **Supabase account** (free) for authentication - [Sign up here](https://supabase.com)

### Quick Start

Get up and running in under 5 minutes:

1. **Clone the repository**
   ```bash
   git clone https://github.com/RafiulM/next-shadcn-dashboard-starter.git
   cd next-shadcn-dashboard-starter
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. **Set up environment variables**
   ```bash
   cp .env.example .env.local
   ```
   
   Open `.env.local` and add your Supabase credentials:
   ```env
   # Get these from https://supabase.com/dashboard/project/_/settings/api
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```
   
   **How to get Supabase credentials:**
   1. Create a free account at [supabase.com](https://supabase.com)
   2. Create a new project
   3. Go to Project Settings → API
   4. Copy the "Project URL" and "anon public" key

4. **Run the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

5. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000) to see your dashboard!

### First Time Setup

After starting the development server:

1. **Create an account**: Go to `/sign-up` to register
2. **Sign in**: Use `/sign-in` to access the dashboard
3. **Explore**: Navigate through the dashboard sections:
   - Overview with charts and analytics
   - Employee management with CRUD operations
   - Product management
   - Kanban board for task management
   - Profile settings

## 🔧 Environment Configuration

### Required Environment Variables

Create a `.env.local` file in the root directory with the following variables:

```env
# Supabase Configuration (Required)
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### Getting Supabase Credentials

1. **Create a Supabase Account**
   - Visit [supabase.com](https://supabase.com)
   - Sign up for a free account

2. **Create a New Project**
   - Click "New Project"
   - Choose your organization
   - Enter project name and database password
   - Select a region close to your users

3. **Get API Keys**
   - Go to Project Settings → API
   - Copy the "Project URL" (this is your `NEXT_PUBLIC_SUPABASE_URL`)
   - Copy the "anon public" key (this is your `NEXT_PUBLIC_SUPABASE_ANON_KEY`)

4. **Set up Authentication (Optional)**
   - Go to Authentication → Settings
   - Configure your site URL: `http://localhost:3000` for development
   - Add production URLs when deploying

## 🐛 Troubleshooting

### Common Issues and Solutions

#### **Build Failures**

**Issue**: `npm run build` fails with dependency errors
```bash
# Solution 1: Clean install
rm -rf node_modules package-lock.json .next
npm install
npm run build

# Solution 2: Force install
npm install --force

# Solution 3: Use different package manager
yarn install && yarn build
# or
pnpm install && pnpm build
```

#### **Environment Variables**

**Issue**: "Invalid API key" or authentication errors
- ✅ Verify `.env.local` exists in root directory
- ✅ Check Supabase URL format: `https://your-project.supabase.co`
- ✅ Verify anon key starts with `eyJ`
- ✅ Restart development server after changing env vars

#### **Supabase Configuration**

**Issue**: Authentication not working
```bash
# Check your Supabase project settings:
# 1. Go to Authentication → Settings
# 2. Add your site URL: http://localhost:3000 (dev) or your production URL
# 3. Ensure email confirmations are configured correctly
```

#### **Node.js Version Issues**

**Issue**: Compatibility errors with Node.js
```bash
# Check your Node.js version
node --version

# Should be 18.17.0 or higher
# Use nvm to manage Node.js versions:
nvm install 18.17.0
nvm use 18.17.0
```

#### **TypeScript Errors**

**Issue**: Type errors during development
```bash
# Regenerate TypeScript definitions
rm -rf .next
npm run dev

# Check TypeScript configuration
npx tsc --noEmit
```

#### **Styling Issues**

**Issue**: Tailwind styles not applying
- ✅ Verify `tailwind.config.ts` includes all content paths
- ✅ Check `globals.css` imports Tailwind directives
- ✅ Restart development server
- ✅ Clear browser cache

#### **Development Server Issues**

**Issue**: Port already in use
```bash
# Find and kill process using port 3000
lsof -ti:3000 | xargs kill -9

# Or use a different port
npm run dev -- -p 3001
```
